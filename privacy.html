NavPost privacy policy

Last updated: 28 October 2026

NavPost is a private tool run by the owner of TheNavZone for their own YouTube channel and Instagram account. It has no other users.

What it accesses

With the owner's permission (Google OAuth), NavPost uses the YouTube Data API to upload the owner's own videos and to read and update their videos, playlists, thumbnails, captions, translations and channel statistics. It uses the Instagram Graph API in the same way for the owner's Instagram account.

How data is stored

Access tokens and settings are stored only on the owner's own computer. NavPost does not collect data about viewers or any other person, does not sell or share data with anyone, and does not use data for advertising.

YouTube

NavPost uses YouTube API Services. By using it you agree to the YouTube Terms of Service; see the Google Privacy Policy. Access can be revoked at any time at Google security settings.
