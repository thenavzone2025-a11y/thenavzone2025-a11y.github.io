NavPost

NavPost is a private posting tool used by the owner of the gaming channel TheNavZone (YouTube) and @the_nav_zone (Instagram).

It schedules, uploads and updates the channel owner's own PS5 gameplay videos (titles, descriptions, translations, thumbnails, playlists) using the official YouTube Data API and Instagram Graph API. It is not offered to the public and has no other users.
